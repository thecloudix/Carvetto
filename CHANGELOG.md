- T-0357: robustness — saves are crash-safe (temporary file, fsync, atomic rename, previous file kept as `<name>.bak`; injected failures leave the old file valid), autosave writes a recovery snapshot at the Options interval while there are unsaved changes and the next start offers to recover it (a clean exit or autosave off removes it), files over 1.5 GiB are refused with a message, and a corpus test checks truncated/corrupt `.carv` files give an error and never change the session (ADR-0128).
