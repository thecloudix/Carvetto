# Changelog

## Unreleased

- T-0014: document hardening — `checkIntegrity()` reports `IdKeyMismatch` for an object whose stored id differs from its map key and counts stored ids in `DuplicateId`, and runs in O(N log N) on deep or wide group trees (iterative loop detection, set-based child lookup; tests with a 60 000-deep chain, a 200 000-child group and a loop closed at depth 50 000) (ADR-0007 amendment A3); the 10 000-op undo/redo timing test now measures process CPU time (best of 3) and asserts time(20k) < 3 × time(10k) to catch O(n²) regressions under parallel load; CI runs `ctest -j8 --repeat until-fail:3`.
- T-0004: `offsetOpenContour` returns every chain (`std::vector<Contour>`, ordered along the input) instead of the longest; chains never cross or touch themselves (cut into tail / closed loop / tail), mitre and chamfer stubs past a trim point are pruned, overlapping mitre extensions deduplicated, and grid-accelerated splitting/pruning offsets a 2000-span polyline in well under 0.1 s (Release) (ADR-0012).
- T-0013: preset-id guard — `AddObjectCommand`, `AddLayerCommand` and `AddSheetCommand` refuse (no-op, nothing recorded) a caller-supplied id already used by any sheet, layer or object or below the generator's next id, so an id freed by undo cannot be re-taken; `checkIntegrity()` reports `DuplicateId` for an id shared across kinds; regression and fixed-seed randomized undo/redo tests (ADR-0007 amendment A2).
- T-0011: id overflow guard — `IdGenerator::kMaxId` (2^62) ceiling in `document/ids.hpp`; the generator never wraps (`tryAllocate`, `canAllocate`, `remaining`, `exhausted`; `reserveThrough` clamps), allocating commands (add object/layer/sheet, paste, group) become no-ops when ids run out, `checkIntegrity()` reports `IdOutOfRange` / `IdNotBelowNext`, with unit tests and a fixed-seed near-ceiling randomized test (ADR-0007 amendment A1).
- T-0060: Qt app shell — main window with 2D/3D view tabs, rulers, sheet/layer selectors, left (Design, Sheets, Layers, Components, Library) and right (Toolpaths) docks, status-bar cursor position in display units, File > New Job dialog, and a headless `carvetto --self-test`; view logic (view transform, nice-number rulers with exact labels, screen-tolerance polygonisation, cursor formatting, New Job validation) lives in the Qt-free `carvetto_viewmodel` library with Catch2 tests (ADR-0014).
- T-0002: span intersections and contour utilities — `geometry/intersect.hpp` (analytic line/arc intersections with `tangent` flag and collinear/coincident `Overlap` intervals, Bezier pairs by polygonisation + Newton/golden-section refinement, contour–contour and self-intersection detection) and `geometry/contour_ops.hpp` (exact signed area/orientation, winding number and point-in-contour with even-odd/non-zero fill rules, closest point on span/contour), with Catch2 tests (ADR-0009).
- T-0003: polygon offsets and booleans via Clipper2 1.4.0 (FetchContent, pinned) — `offsetContours` (round / sharp-with-mitre-limit / square joins, open contours outlined), `offsetOpenContour` (exact single-sided left/right offset of lines and arcs: joins at outside corners, arcs extended for sharp/square corners, consumed spans pruned so every point stays ≥ d from the input), `booleanOp` (union / difference / intersection / xor, NonZero or EvenOdd fill, open subjects clipped) and `unionContours`; fixed-point scale `kFixedPointScale` documented in ADR-0006; Catch2 tests.
- T-0030: `.pp` post-processor interpreter — parser for global settings, `VAR` specs (A/C modes, incremental, prefix, `[+]W.D` format, multiplier), `begin/end` blocks with quoted output lines and `+` comments; interpreter for header/tool change/new segment/move/footer blocks with first-move and missing-block fallbacks, modal suppression, line numbering with wrap, inch scaling, arc I/J and R forms with linearisation, inverse time and rotary wrap; shipped `posts/grbl_mm.pp` with a golden-file test (ADR-0011).
- T-0010: document model — `Job` (single/double/rotary, mm internally with display `Units`, Z-zero, XY datum + offset), `Sheet`, `Layer`, `Object` (vector with contours + creation-parameter variant, bitmap placeholder, group), monotonic 64-bit ids, `Selection`, `DocumentVariables` (naming rule, references, text import/export), command-based `UndoStack` with coalescing and macros, the concrete object/layer/sheet/job/variable commands with group-integrity rules (ungroup splices, delete-layer dissolves groups, layer/sheet moves follow the group tree), and `Document::checkIntegrity()` exercised by a randomized undo/redo test, with Catch2 tests (ADR-0007).
- T-0040: toolpath core — `Move` (rapid/feed/plunge/retract/arcCW/arcCCW/dwell, 3D endpoint, arc centre, feed override, dwell seconds), `Vec3`, `Toolpath` with `ToolSnapshot`, bounds and length by kind, `PassPlan` (exact-step / equalised passes, last-pass thickness), contour linking with safe-Z rapids and plunge/retract, and a deterministic trapezoidal-acceleration time estimate, with Catch2 tests (ADR-0008).
- T-0020: tooling module — `ToolType` (9 types), `Tool` with per-type cutting width at depth, `CuttingData` keyed by (machine, material) with default fallback, `Material`, `Machine` (accelerations, associated posts), `ToolDatabase` (groups, CRUD, duplicate machine/material with cutting data, merge with/without overwrite) and deterministic JSON import/export via nlohmann/json 3.11.3 (ADR-0010).
- T-0001: geometry primitives — `Box2`, `Transform2` (2×3 affine: compose/invert/apply), `Span` variant of `LineSpan`/`ArcSpan`/`BezierSpan`, `Contour`, `Polyline`, `Tolerance`; length, bounds, point-at-parameter, reverse, transform and polygonisation at a chordal tolerance, with Catch2 tests (ADR-0005).
- Repository scaffold: CMake project, `carvetto_core` library with basic 2D primitives, Catch2 tests, CI, agent workflow and backlog.
