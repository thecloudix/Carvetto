# Aspire Trial Edition 12.511 — observed on Chris's PC (2026-10-24)

## Startup screen
Create new file / New from template / Open existing; recent files; tutorial video browser & tutorial files folder; links (V&Co, website, support, forum, EasyCreate, social); Clipart & Projects (Design & Make).

## Job Setup panel
- Job Type: Single Sided / Double Sided / Rotary
- Job Size: Width X, Height Y, Thickness Z; Units inches/mm
- Z Zero: Material Surface / Machine Bed
- XY Datum: 5-point picker (corners + center) + Use Offset X/Y
- Modeling Resolution: Standard (1M points, fastest) / High (3x slower) / Very High (7x slower)
- Material Settings: appearance (e.g. Canadian Maple) or solid color

## Main window
- 2D View / 3D View tabs; tile horizontal/vertical split
- Toolbar selectors: Sheet, Layer, Level
- Left dock tabs: Design, Sheets, Layers, Components (tree by Level), Clipart (Library Browser / Local Files, library folders: Clipart, Design&Make, download)
- Right dock: Toolpaths (Material Setup, Home Pos, XY datum, Toolpath Operations grid, toolpath list per sheet)
- Design panel groups: File Operations (6), Create Vectors (14), Transform Objects (6), Edit Objects (22), Offset and Layout (6), Modeling Tools (~25)
- Toolpaths panel: ~18 operation icons + ~17 toolpath-management icons (preview, templates, save toolpath, summary, job sheet, etc.)
- Status bar with cursor XY; Job Dimensions readout
