# Bundled fonts (T-0211)

`CarvettoStarter-Regular.ttf` is the font the Text tool starts with. It is the same original Carvetto
font as the test fixture `core/tests/fixtures/text/CarvettoTest-Regular.ttf` (see the README there;
generated by `tools/make_test_font.py`), licensed under the SIL Open Font License 1.1 (`OFL.txt`).
It only has a handful of glyphs (I, T, O, a few more), so it proves the pipeline but is not a
usable text face: users pick their own TTF/OTF file in the Text tool, and the chosen font is
embedded in the `.carv` file. Choosing a real, redistributable starter font is an owner decision
(follow-up card).

The font is compiled into the program (`app/viewmodel`, generated source), not read from disk.
