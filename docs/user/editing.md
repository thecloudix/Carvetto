# Editing

## Selecting

Use the Select tool: click an object, or drag a marquee around several. Undo and redo are in the Edit menu.

## Node editing

Choose the Node Edit tool (shortcut N). Drag nodes and control points; Shift adds a node; Ctrl+drag moves a
span; right-click for the node menu (including Keep Bezier Tangency, Mirror Mode and Properties).

## Transforms

The **Transform** menu moves, scales, rotates, mirrors and aligns the selection; **Transform > Align** holds
the alignment commands.

## Vector operations and copies

**Edit > Vectors** holds operations such as joining, trimming, offsetting and combining shapes.
**Edit > Copies** makes arrays and other repeated copies.

## Keep-out zones and double-sided jobs

**Edit > Keep-out Zones** marks areas that toolpaths must avoid (for example clamps).
**Edit > Double-sided** sets up jobs machined from both faces.
