# 3D relief

A relief is a height map: a surface that varies in Z over the material. Carvetto can create reliefs from
shapes, import them from meshes, edit them like clay and cut them with roughing and finishing toolpaths.

- **File > Import 3D Model...** reads STL and OBJ meshes and converts them to a relief.
- Create, combine and modify reliefs in the modelling panel; the sculpting tools raise, lower and smooth the surface.
- **File > Export 3D Model** writes the relief back out in an open mesh format.
- Roughing and finishing toolpaths are added from the Toolpaths panel and simulated in the Preview panel.
- **File > Create Component From Toolpath Preview** turns a simulated result into a new component.
