# FAQ

**Where are my files saved?** Where you choose, as `.carv` jobs; the format is described in
[its design record](../adr/0003-native-file-format.md).

**The G-code does not look right on my controller.** Check the post in your machine definition and read the
[post guide](../../posts/README.md).

**Can I change the language?** Yes, in **Setup > Options...**; it applies on the next start.

**Is the program free?** Yes, it is open source; see the licence file in the source repository.

**Can I use my own gadgets?** Yes, see [gadgets](gadgets.md).
