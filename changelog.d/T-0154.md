- T-0154: no-spindle toolpaths for diamond-drag engraving (owner decision 2026-11-03; ADR-0020, ADR-0024 §6) — Quick Engrave accepts diamond-drag tools again (Outline and Fill, moving exactly like an end mill of the same diameter) and marks their tool snapshot `spindleOff` with spindle speed 0, the only exemption from T-0134's spindle speed > 0 rule; the post leaves out the spindle start lines of HEADER/TOOLCHANGE/NEW_SEGMENT and SPINDLE_ON for such a toolpath and writes the new `SPINDLE_OFF_PAUSE` block before it (every shipped post: `M5`, safe Z, an ASCII message to check that the spindle is stopped or locked, `M0`, safe Z), refuses posts without that block (or whose pause blocks write no M5/M0), `[S]` lines that carry other codes and any M3/M4/S word in the drag output (every line written in a drag section must pass an allowlist: printable ASCII without Grbl realtime characters or Marlin emergency codes, plain comments ending at the first ')', and live G-code made only of X Y Z I J F P N T H words, G0 G1 G2 G3 G4 G17 G20 G21 G40 G43 G49 G80 G90 G91 G91.1 G94 and M0 M1 M2 M5 M6 M30, plus Marlin's M0 message text; non-ASCII output text is a parse error for every post), and spindle-off toolpaths whose snapshot is not a diamond drag tool, and restarts the spindle afterwards only through TOOLCHANGE + SPINDLE_ON, after the new `SPINDLE_UNLOCK_PAUSE` block (once per drag section, also before the program end when the job ends with drag toolpaths, `M0` asking the operator to unlock the spindle; posts without it refuse such jobs); Profile and Pocket refuse diamond-drag tools (`InvalidTool`, pointing to Quick Engrave); job.json `tool.spindle_off` with `tool.tool_type: "diamond_drag"` (both written only for spindle-off snapshots, format stays 1.1) is refused unless the record is an engrave of a diamond drag tool by the loader, `saveCarv` and the toolpath commands. Every other toolpath kind with spindle speed 0 is still refused by every shipped post (tested); new goldens `post/<post>_drag.nc` for all eight posts; existing goldens unchanged.
