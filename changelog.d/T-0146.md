- T-0146: changelog fragments — each card writes its entry to `changelog.d/T-XXXX.md` (or `T-XXXX-YYYY.md` for one entry covering several cards) instead of editing `CHANGELOG.md`, so merges no longer make every open PR conflict; `tools/changelog.py check` validates the fragments (name matches a card in the backlog, exactly one bullet line with the matching `- T-XXXX:` prefix, no control or invisible characters, one fragment per card) and with `--base <ref>` refuses a PR that edits the Unreleased section by hand, except for lines coming from fragments the same PR deletes; `tools/changelog.py assemble` inserts the fragments under "## Unreleased" newest card first and deletes them (deterministic, idempotent); CI runs both on every PR, ctest runs the check and the script's unit tests (`tools.changelog_check`, `tools.changelog_unit`).
